# AI Slop Thresher privacy notice

Publisher: Burntgogi. Updated: 5 October 2026.

AI Slop Thresher contains editing instructions, reference documents, and display assets. It has no bundled MCP server, executable, analytics, publisher account, or external service connection. The package does not send drafts, uploaded files, or conversation content to the publisher.

The publisher collects no personal data through the plugin, has no recipients to which plugin inputs are disclosed, and retains no plugin inputs. The publisher therefore has no stored plugin inputs to access or delete.

ChatGPT, Codex, or another host processes the text and files you provide according to that host's privacy policy, account settings, and available controls. This notice does not replace the host's policies or describe its retention practices. You control which text and files you provide and may remove or disable the plugin through the host.

If you post a support issue on the public GitHub repository, the information you submit is visible according to GitHub's rules. Use a short invented example when reporting a problem, and omit credentials, personal information, and confidential drafts. Support issues are separate from plugin inputs. GitHub hosts those issues under its own privacy and retention practices; use GitHub's editing and deletion controls for information you post there.

Questions can be raised at the [project issue tracker](https://github.com/Burntgogi/ai-slop-thresher/issues).
