# 라이선스 검토

2026년 9월 12일. 첫 공개 릴리즈는 사용자의 선택에 따라 Apache-2.0으로 확정했다.

Apache-2.0은 특허 허락과 기여·재배포 조건을 명시한다. 이 프로젝트는 해당 조건으로 배포하며 LICENSE, NOTICE와 출처 문서를 함께 제공한다. 다음 표는 선택 과정에서 확인한 두 라이선스의 차이다.

| 비교 항목 | MIT | Apache-2.0 |
| --- | --- | --- |
| 상업적 사용·수정·재배포 | 허용 | 허용 |
| 파생물의 소스 공개 의무 | 없음 | 없음 |
| 기본 고지 | 저작권 고지와 라이선스 문구 보존 | 라이선스 제공, 관련 고지 보존, 수정 파일에 변경 사실 표시 |
| 특허 | 명시적인 특허 허락 조항 없음 | 기여자의 해당 기여에 적용되는 특허 허락과 특정 특허 소송 시 종료 조건을 명시 |
| NOTICE | 별도 규정 없음 | 배포물에 NOTICE가 있으면 해당하는 고지를 파생 배포물에도 보존 |

MIT 조건은 [GitHub Choose a License의 MIT 원문](https://choosealicense.com/licenses/mit/)에서, Apache-2.0의 특허와 재배포 조건은 [Apache 공식 라이선스 3·4절](https://www.apache.org/licenses/LICENSE-2.0)에서 확인했다. Apache는 자체 프로젝트에 적용할 때 LICENSE 사본을 포함하고 NOTICE 작성도 고려하도록 [공식 FAQ](https://www.apache.org/foundation/license-faq.html#Apply-My-Software)에 안내한다. 새 Apache 프로젝트에 NOTICE 파일이 언제나 필수라는 뜻은 아니다.

참고 프로젝트와 반영한 내용을 적는 일은 프로젝트 자체의 라이선스 선택과 별도로 한다. 현재의 [출처 문서](../ATTRIBUTIONS.md)는 설계와 화면을 참고한 경로를 설명한다. 실제로 타인의 코드·문구·자산을 복제하거나 수정해 포함하는 경우에는 그 부분에 적용되는 원래 라이선스 조건과 고지를 지켜야 하며, 링크 하나가 이를 대신하지 않는다.

배포 조건의 원문은 [LICENSE](../LICENSE), 저작권 고지는 [NOTICE](../NOTICE)에 있다. 참고 저장소의 라이선스는 해당 원저작물에 계속 적용된다.
