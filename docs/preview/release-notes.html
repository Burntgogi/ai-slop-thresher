AI Slop 탈곡기 v1.1.0

이 글은 흥미롭지 않습니다.

2026년 9월 12일 · 첫 공개 릴리즈

v1.1.0은 기존 humanizer의 이름을 ai-slop-thresher로 바꾸고 짧은 호출 $thresh를 추가한 버전입니다. 원문의 뜻과 말투를 보존하는 편집 지침은 그대로 사용합니다.

이름과 호출

항목 v1.1.0
한국어 이름 AI Slop 탈곡기: 이 글은 흥미롭지 않습니다.
영어 이름 AI Slop Thresher: This Text Is Not Interesting.
정식 호출 $ai-slop-thresher
짧은 호출 $thresh

thresh는 본 스킬의 지침을 읽는 짧은 호출용 스킬입니다. 두 이름으로 같은 편집 기준을 적용합니다. 부제는 제품 소개에만 쓰며 윤문한 본문에 자동으로 붙이지 않습니다.

함께 준비한 문서와 이미지

파란 픽셀 아트와 흰 고양이로 타이틀 배너를 만들었습니다. 긴 원고에서 군더더기를 털어내는 탈곡기를 그렸습니다.

README에는 설치 순서, 적용 전후 예시와 요청별 사용법을 담았습니다. README와 이 릴리즈 노트에도 탈곡기 지침을 적용했습니다. 상투적인 도입과 반복 설명을 줄인 과정은 윤문 기록에 남겼습니다.

설치와 이전 버전 전환

새로 설치할 때는 README의 설치 안내를 따르세요. ZIP 안의 ai-slop-thresher와 thresh를 같은 스킬 디렉터리에 넣습니다. 스킬 전용 API 키나 Python은 필요하지 않습니다.

기존 humanizer 사용자는 새 이름의 두 스킬을 설치한 뒤 $thresh로 짧은 글을 다듬어 보세요. 사용하던 $humanizer 호출은 새 이름으로 바꿉니다. 직접 수정한 지침이 있다면 먼저 보관하고, 새 설치를 확인한 뒤 이전 폴더를 정리합니다.

검증

두 스킬의 형식 검사, 짧은 호출의 참조 경로, 소스와 배포 ZIP의 파일 일치를 확인했습니다. 스킬 ZIP에는 본 스킬 4개 파일과 짧은 호출용 스킬 2개 파일이 들어 있습니다.

이름을 바꾸기 전 완료한 5회 개선 기록과 20개 예문을 함께 제공합니다. 이때 사용한 편집 규칙은 v1.1.0에서도 유지합니다. 당시 기록은 humanizer 1.0.0이라는 이름과 버전을 보존했습니다. 검사 방법과 범위는 재검증 안내에서 확인할 수 있습니다.

참고 자료

휴머나이저 저장소 7개와 화면·문서 구성을 참고한 저장소 2개를 출처 표에 정리했습니다. 각 항목에서 반영한 내용, 읽은 리비전과 라이선스 원문을 확인할 수 있습니다.

라이선스와 배포 파일

Apache-2.0으로 배포합니다. 두 ZIP에 LICENSE, NOTICE와 ATTRIBUTIONS.md를 포함했습니다. 스킬 ZIP은 지침·참조 파일 6개와 고지 문서 3개로 구성됩니다.

전체 제작 자료에는 배너, README, 예문과 검증 기록을 함께 담았습니다. 로컬 설치 경로가 적힌 기록과 임시 도구는 공개 자료에서 제외했습니다. 릴리즈에 첨부한 SHA256SUMS로 두 ZIP의 체크섬을 대조할 수 있습니다.
