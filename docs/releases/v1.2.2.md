# AI Slop 탈곡기 v1.2.2

2026년 10월 7일 작성. 스킬, Codex 플러그인, Claude Code 플러그인을 하나의 번호 1.2.2로 묶은 릴리즈다. 공개 디렉터리 제출을 준비하던 Codex 플러그인 1.2.2는 스킬 1.2.1을 담는 별도 번호였으나 이번 릴리즈에서 합쳤다.

## 변경 내용

v1.2.1을 모델로 실행해 비교한 결과, 실제 표시 문구를 감싼 곧은 따옴표를 둥근 따옴표로 바꾸는 퇴보가 있었다. 보존하는 따옴표와 기호는 모양도 바꾸지 않도록 지침에 적었다. v1.2.0에서 설명에서 빠졌던 호출 단서 사람 글처럼 다듬기를 되살렸다. 나머지 편집 규칙은 v1.2.1과 같다. [실행 비교 기록](../../evaluation/regression-20261007/README.md)

단축 스킬 thresh는 이름을 직접 부를 때만 쓴다. Codex에서는 자동 선택을 껐고 다른 하네스에는 설명으로 알린다. 본 스킬을 읽지 못하면 누락된 경로와 설치 방법을 알리고 윤문을 시작하지 않는다.

Claude Code 플러그인 마켓플레이스를 추가했다. 저장소 루트의 공통 스킬을 그대로 사용한다. Codex 플러그인에는 공개 디렉터리용 소개, 아이콘, 개인정보와 라이선스 안내를 넣었다. 스킬과 두 플러그인의 버전이 다르면 테스트가 실패한다. [하네스별 설치](../installation.md)

저장 사례 검사가 보고서에 쓰인 최종 결과를 직접 검사한다. 이전에는 최종 결과를 망가뜨려도 검사가 통과했다. 지정한 사례에서는 수치가 대상어 뒤에 원래 순서로 남았는지도 확인한다. [재검증 안내](../verification.md)

README에 소개 기사의 적용 전후 비교 이미지와 [기사 편집 기록](../../reports/article-demo/README.md)을 추가했다. 이 기록은 v1.1.0 지침으로 편집한 결과다.

## 평가와 한계

배포된 v1.2.0과 v1.2.1을 Codex `gpt-6.1-sol`(xhigh)로 고정 사례 20개와 탐침 7개에 두 번씩 실행했다. 두 버전 모두 의미 손실은 없었다. v1.2.1은 지시 대상이 모호한 공지에서 문장 위치를 조정해 읽기 쉬워졌고, 따옴표 모양을 바꾸는 퇴보가 한 사례에서 있었다. 1.2.2는 이를 고친 뒤 해당 사례와 관련 사례를 다시 실행해 확인했다.

같은 모델 계열 하나와 사례당 두 번 실행한 합성 자료다. 문체 선호는 평가하지 않았으며 모든 문서에서 이전 버전보다 낫다고 주장하지 않는다. 평가 기록마다 다르게 쓴 X/Y, A/B/C 라벨은 [평가 라벨 대응표](../evaluation-labels.md)에 정리했다.
