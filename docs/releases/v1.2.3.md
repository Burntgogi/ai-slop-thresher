# AI Slop 탈곡기 v1.2.3

2026년 10월 7일 작성. 편집 지침 본문은 v1.2.2와 같다. 배포 구조와 검증을 보완한 릴리즈다.

## 변경 내용

Codex와 Claude Code가 플러그인 폴더 하나 `plugins/ai-slop-thresher/`를 함께 쓴다. 이전에는 Claude Code 플러그인이 저장소 전체를 가리켜 설치 캐시에 평가 자료까지 약 13MB가 복사됐다. 이제는 플러그인 폴더만 복사된다. Codex CLI도 `codex plugin marketplace add Burntgogi/ai-slop-thresher --ref main`으로 같은 저장소에서 설치할 수 있다. [하네스별 설치](../installation.md)

Claude Code 플러그인의 thresh에 `disable-model-invocation: true`를 넣어 Codex의 `allow_implicit_invocation: false`와 짝을 맞췄다. 두 스킬에는 입력 안내 `argument-hint`도 넣었다. 이 필드들은 `integrations/claude-code/`에서 관리해 생성본에만 더하며, 공통 스킬과 Codex 공개 디렉터리용 ZIP은 Agent Skills 필드만 유지한다.

README와 릴리즈 노트 미리보기에 원본의 해시를 기록하고, 미리보기가 낡았거나 링크·앵커가 깨지면 테스트가 실패한다. 1.1.0 이후 다시 만들지 않은 미리보기를 이번 점검에서 찾았기 때문이다. 1.1.0 당시의 브라우저 검사 기록은 `research/history/`로 옮겼다.

검사기는 같은 뜻으로 인정할 표현을 별도 파일로 받는다. 2026-10-07 실행 비교의 출력 118개를 다시 판정하면 문자 일치 오탐이 사라지고 실제 퇴보였던 v1.2.1의 따옴표 변경 2건만 남는다. 실행 비교를 다음 릴리즈에도 쓸 수 있도록 도구로 정리했다. [실행 비교 도구](../../evaluation/regression/README.md)

GitHub Actions에서 테스트와 검사를 실행한다. 릴리즈 전 점검, 본문 생성, 공개 후 자산 대조를 `scripts/release.py`로 묶고 [릴리즈 절차](../releasing.md)에 적었다.

## 한계

Claude Code와 Codex는 카탈로그를 추가할 때 저장소 전체를 내려받는다. 홈 경로가 긴 Windows 환경에서는 `git config --global core.longpaths true`가 필요할 수 있다. 편집 지침은 바뀌지 않아 실행 비교를 새로 하지 않았다.
