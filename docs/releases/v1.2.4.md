# AI Slop 탈곡기 v1.2.4

2026년 10월 7일 작성. 편집 지침 본문은 v1.2.2와 같다. Codex 카탈로그 이름을 정리한 릴리즈다.

## 변경 내용

Codex 카탈로그 이름을 `ai-slop-thresher-local`에서 `ai-slop-thresher`로, 표시 이름을 "AI Slop 탈곡기 로컬 배포"에서 "AI Slop 탈곡기"로 바꿨다. v1.2.0에서 저장소 안의 로컬 배포용으로 만든 이름이 v1.2.3의 GitHub 설치에도 그대로 쓰였기 때문이다. 이제 Codex와 Claude Code 모두 `ai-slop-thresher@ai-slop-thresher`로 설치한다. 두 카탈로그 이름이 다르거나 문서의 설치 이름과 맞지 않으면 테스트가 실패한다. [하네스별 설치](../installation.md#codex-플러그인)

카탈로그 이름은 설치 출처를 가리킬 뿐이며 호출명 `$thresh`, `$ai-slop-thresher`와 직접 설치한 스킬과의 관계는 바뀌지 않는다. 직접 설치와 플러그인 설치를 함께 쓰면 같은 스킬이 두 번 보일 수 있으므로 한 방식을 고른다.

## 옮기는 방법

Codex는 카탈로그 이름을 고정한 시점의 파일에서 읽는다. v1.2.3 이하의 `-local` 카탈로그로 설치했다면 이름이 바뀐 뒤 기존 설치가 목록에서 사라지지만 설정에는 남는다. `codex plugin remove ai-slop-thresher@ai-slop-thresher-local`, `codex plugin marketplace remove ai-slop-thresher-local`을 실행한 뒤 새 이름으로 다시 추가한다. 이 순서는 임시 Codex 환경에서 확인했다. `--ref v1.2.3` 이하로 고정해 쓰는 경우에는 기존 설치 이름을 그대로 쓴다.
