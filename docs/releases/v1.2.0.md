# AI Slop 탈곡기 v1.2.0

2026년 9월 30일.

2026년 10월 1일 최종 검토: v1.2.0을 기본으로 유지하고, 사용자가 같은 원문으로 두 버전의 사용 경험을 비교해 더 만족하는 버전을 선택하도록 합니다. 새 버전의 전반적인 문체 우위는 확인하지 못했습니다. [버전 선택 안내](../../docs/version-choice.md) · [추가 문서와 최종 검토](../../reports/final-review-20261001.md). 이 후속 문서는 원래 v1.2.0 태그와 배포 ZIP의 내용을 바꾸지 않습니다.

공통 윤문 스킬과 Codex 플러그인을 분리했습니다. 앞 문장을 부정하고 같은 내용을 다시 정의하는 반복 수사는 덜고, 실제 정정·책임·조건·불확실성과 저자 평가는 보존하도록 다듬었습니다.

## 설치와 배포

`skills/`는 하네스 중립 원본입니다. Codex 메타데이터는 `integrations/codex/agents/`에서 관리하고 `plugins/codex/ai-slop-thresher/`를 생성합니다. Codex, Claude Code, OpenCode, Cursor와 직접 지정 경로에 맞춰 설치할 수 있습니다. 설치 기본값은 미리보기이며 `--apply`를 붙여야 복사합니다. 기존 스킬은 덮어쓰지 않습니다.

| 파일 | 용도 |
| --- | --- |
| `ai-slop-thresher-portable.zip` | Codex 외 하네스에서도 사용할 수 있는 공통 스킬 두 개 |
| `ai-slop-thresher-codex-plugin.zip` | Codex manifest·메타데이터와 공통 스킬을 포함한 플러그인 |
| `ai-slop-thresher.zip` | 기존 다운로드 이름. portable ZIP과 동일 |
| `ai-slop-thresher-workbench.zip` | 제작·감수·평가와 배포 자료 |
| `SHA256SUMS` | 위 네 ZIP의 SHA-256 |

두 스킬 `ai-slop-thresher`와 `thresh`는 함께 설치합니다. 법적 고지와 상대 참조를 포함합니다. [하네스별 설치 안내](../../docs/installation.md)를 확인하세요. 사용자 하네스에 실제 설치하거나 설정을 변경한 것은 아닙니다.

## 윤문 규칙

불필요한 부정·재정의·문제 축소 표현을 문구 패턴만으로 지우지 않습니다. 독자의 판단에 필요한 고유한 명제인지 확인합니다. 실제 정정, 책임 주체, 피해, 남은 조치, 배타 조건과 불확실성은 보존하고, 원문에 없는 안심이나 긍정적 재해석은 추가하지 않습니다. 모호한 우선순위나 저자의 관점을 임의로 바꾸지 않습니다.

## 제작과 감수

초기 제작 후 다섯 차례 재귀 개선을 수행하고 합성 입력의 실제 에이전트 출력 82건을 보존했습니다. Codex의 독립 감수, Dot VM의 Linux 실행 검증, Muse의 핵심 10개 파일 정적 감수를 받았습니다. Dot이 발견한 이중 복구 실패 시 백업 삭제 결함을 수정했습니다.

Windows 전체 검사 34개 중 31개 통과·3개 건너뜀, Dot Linux distribution 검사 33개 중 32개 통과·1개 건너뜀입니다. 건너뛴 항목과 각 검토자의 범위는 [개선 핵심 보고서](../../reports/improvement-20260930.md)에 명시했습니다. 같은 환경에서의 ZIP 재현성을 확인하며, 다른 OS·Python·압축 라이브러리의 ZIP 해시까지 같다고 보장하지 않습니다.

v1.1.0과 실제 릴리즈 ZIP을 비교하는 A/B 평가를 완료했습니다. 합성 사례 28건을 버전마다 두 번 실행한 112개 출력의 의미 보존 판정은 두 버전 모두 55/56, 요청 준수는 56/56이었습니다. 문체는 이전 버전 우세 10쌍·새 버전 우세 5쌍·동률 40쌍, 비교 제외 1쌍입니다. 새 버전의 전반적인 품질 우세는 확인하지 못했습니다. 태그의 최초 배포물은 유지하고 결과를 별도 첨부합니다. [A/B 결과 보고서](../../reports/ab-comparison-20260930.md) · [사전 계획](../../evaluation/ab-20260930/protocol.md)

## 한계

합성 예문과 같은 Codex 모델 계열의 에이전트 평가이며 독립 인간 평가나 모델 간 일반화 근거는 아닙니다. 실제 하네스 UI 설치·자동 선택·원격 VM 동기화와 AI 탐지기 통과율은 검증하지 않았습니다. 최종 Muse 감수는 사용자 PC Chrome을 사용했으므로 전체 과정을 PC 브라우저 없이 완료했다고 주장하지 않습니다.
