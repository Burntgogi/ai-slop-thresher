# AI Slop 탈곡기 v1.2.1

2026년 10월 2일. 기존 윤문·의미 보존과 하네스별 배포 구조에 사용자 피드백을 반영한 가독성 개선을 통합했다.

## 변경 내용

정보 없는 흥미·칭찬 반응을 삭제하고 함께 담긴 사실·근거·조건·조치는 남긴다. 서평의 감상과 실제 발화의 인용처럼 표현 자체가 내용이면 보존한다.

반복 지칭과 긴 구문, 겹친 절과 명사화를 줄이되 조건·범위·개별 적용 단위를 유지한다. 기능 있는 조사·접속 표현·쉼표를 보존하며 특정 표현이나 기호의 개수를 품질 목표로 삼지 않는다. 자연스러운 동사절로 관계를 드러낼 수 있지만 이미 적절한 문장은 유지한다.

독자의 판단·행동에 필요한 전제가 늦게 나오거나 같은 역할의 정보가 흩어져 읽기 어려울 때만 묶음과 위치를 조정한다. 이동한 조건·예외의 적용 대상과 지시어의 선행 대상을 확인하고 원문에 없는 인과·대조·우선순위를 만들지 않는다. 장르에 맞는 전개를 유지하고 기승전결이나 같은 문단 틀을 모든 글에 강제하지 않는다.

실제 정정·책임·피해·조건·가능성과 저자의 평가는 기존 기준대로 보존한다. 명사를 꾸미는 가능성·조건도 축약 과정에서 단정으로 바뀌지 않는지 확인한다.

재검증과 재빌드를 분리했다. 사례 검사와 A/B 재집계의 기본 실행은 기존 기록을 쓰지 않는다. ZIP 생성은 명시한 소스 밖의 새 출력 폴더를 요구하며 기존 배포물을 덮어쓰지 않는다. 전체 작업 자료에는 추적된 탈곡기 파일과 명시적으로 추가한 자료만 넣는다. [검사와 재빌드 안내](../verification.md)

## 배포와 사용

공통 지침은 `skills/`, Codex 전용 표시 정보는 `integrations/codex/`, 생성된 플러그인은 `plugins/codex/ai-slop-thresher/`에 둔다. ai-slop-thresher가 정본이고 thresh는 정본을 읽는 짧은 호출 이름이다. Codex 플러그인과 직접 스킬 설치 중 한 방식을 사용한다. [하네스별 설치](../installation.md)

배포 파일은 portable ZIP, Codex plugin ZIP, portable과 같은 호환 이름 ZIP, workbench ZIP과 SHA256SUMS다. 공개 릴리즈에서 받으며 저장소 루트의 이전 `dist/`는 역사 기록으로 유지한다. 이전 버전의 공개 태그·ZIP·평가 기록도 보존했다.

## 평가와 한계

이전 공지 A/B/C에서는 외부 B(v1.1.0) 1명·C(v1.2.0) 2명과 사용자의 별도 C 선호가 있었다. 후속 합성 공지 X/Y에서는 사용자가 X(v1.2.1 후보)를 대체로 선호하면서 두 번째 문단 압축과 논리적 정보 배열을 보완하도록 의견을 줬다. 문서와 후보가 다른 평가이므로 합산하지 않는다. [이전 응답](../../reports/abc-human-feedback-20261002.md) · [최신 응답과 언어 검토](../../reports/final-human-feedback-linguistic-20261002.md)

이 의견을 바탕으로 지침을 마무리하고 추가 A/B와 사람 투표는 종료했다. 기존 사례의 회귀 확인과 형식·참조·패키징 검증을 수행했다. 마지막 지침 보완 후 별도의 맹검 생성 실험이나 새 삼자 감수는 하지 않았다. 이전 Codex·Dot·Muse 감수는 v1.2.0에 대한 역사 기록이며 이번 릴리즈의 독립 감수로 재사용하지 않는다. 모든 문서에서의 품질 우월성이나 AI 탐지기 통과율을 주장하지 않는다. 확인 결과는 [최종 검토 보고서](../../reports/release-finalization-20261002.md)에 기록한다.

협업 도구 개발과 VM 배치는 별도 세션 범위다. Apache-2.0으로 배포한다. [v1.2.0 노트](v1.2.0.md) · [변경 이력](../../CHANGELOG.md)
