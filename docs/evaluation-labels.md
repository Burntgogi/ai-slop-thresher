## 1.2.1 후보와 배포본

1.2.1이라는 번호는 배포 전 여러 후보에도 쓰였다. 후보 R1, R2, 최종 후보(640fd646)와 별도 빌드 두 개는 모두 배포된 v1.2.1과 본문이 다르다. 사람 평가와 맹검 비교에 쓰인 1.2.1은 모두 후보이며, abc-20261001-r2에서 후보 R2(A)는 응답자 4명 중 아무도 선택하지 않았다. 배포된 v1.2.1을 모델로 실행해 비교한 기록은 regression-20261007이 처음이다.

앞으로는 배포 전 후보를 후보 R1, R2처럼 부르고 배포 번호는 태그를 만든 본문에만 붙인다.
