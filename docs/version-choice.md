# 버전 선택과 복구

현재 배포는 v1.2.4이다. 편집 지침은 v1.2.2와 같으며 Codex와 Claude Code가 플러그인 폴더 하나와 설치 이름 `ai-slop-thresher@ai-slop-thresher`를 함께 쓴다. v1.2.2는 v1.2.1의 편집 규칙에 따옴표 모양 보존을 더하고 스킬과 두 플러그인을 하나의 번호로 묶었다. 특정 문서의 읽기 선호를 모든 문서의 성능 순위로 일반화하지 않는다. 이전 버전의 사용 경험에 만족하면 해당 릴리즈를 계속 사용할 수 있다.

## 확인할 자료

[v1.2.4 변경 내용](releases/v1.2.4.md), [v1.2.3 변경 내용](releases/v1.2.3.md), [v1.2.2 변경 내용](releases/v1.2.2.md)과 [실행 비교 기록](../evaluation/regression-20261007/README.md)에 최신 확인 범위를, [v1.2.1 변경 내용](releases/v1.2.1.md)과 [최종 검토](../reports/release-finalization-20261002.md)에 이전 피드백을 기록했다. 기록마다 다른 라벨은 [평가 라벨 대응표](evaluation-labels.md)에서 확인한다. 추가 비교 실험은 종료했으며 사용자가 새 비교나 투표를 해야 설치할 수 있는 구조는 아니다. 과거 [v1.1.0/v1.2.0 비교](../reports/ab-comparison-20260930.md)와 [추가 공지 비교](../reports/final-review-20261001.md)는 당시 버전의 기록으로 보존한다.

## 설치하거나 이전 버전으로 돌아가기

사용할 버전의 릴리즈에서 ZIP과 SHA256SUMS를 받아 해시를 확인한다. 현재 설치한 ai-slop-thresher와 thresh 두 폴더를 스킬 검색 경로 밖에 백업한 뒤, 같은 릴리즈의 두 스킬을 함께 설치한다. 직접 설치 스크립트는 같은 이름의 기존 스킬을 덮어쓰지 않는다. 플러그인 사용자는 해당 제품의 설치·제거 경로를 따르며 직접 스킬을 중복 등록하지 않는다. [하네스별 절차](installation.md)

복구하려면 현재 두 스킬을 별도로 보관하고 백업한 두 폴더를 원래 위치에 함께 복원한다. 원격 VM의 설치는 자동으로 바뀌지 않는다. 원격 실행에서 사용한 지침 버전은 해당 환경에서 확인해야 한다.

사용 중 의미 손실이나 어색한 표현을 발견하면 버전, 하네스, 원문과 최초 수정문, 사라진 조건 또는 읽기 어려운 부분을 기록해 피드백할 수 있다. 개인정보가 있는 원문을 공개할 필요는 없다.
