# 저장소 선정 기록

기준일은 2026년 9월 12일이며 생성일 범위는 2025년 9월 12일부터 기준일까지다. 별 수 기준은 1,000개 이상이다. GitHub 검색의 created 조건과 REST API의 created_at을 사용했다. 최초 커밋의 날짜나 최근 수정일로 대체하지 않았다.

검색어는 `humanizer stars:>=1000 created:2025-09-12..2026-09-12`와 `"AI writing" stars:>=1000 created:2025-09-12..2026-09-12`였다. 웹 검색으로 발견한 stop-slop도 같은 API로 조건을 검증했다. 검색 결과가 모든 관련 저장소를 포괄한다고 주장하지 않는다.

후보 8개 중 일반 산문·한국어·학술·장르별 윤문에 관련된 7개를 비교했다. RevoltDevScript/Revolt-Script는 같은 조건을 만족했지만 학습 플랫폼 자동화가 중심이어서 산문 편집 스킬의 비교 대상에서 제외했다.

선정 저장소는 모두 GitHub API에서 fork=false였다. 다만 Humanizer-zh는 README에서 blader/humanizer 및 stop-slop의 영향을 명시한다. 따라서 7개를 서로 독립적으로 만들어진 방법 7가지로 취급하지 않는다.

검색 인덱스의 별 수는 과거 캐시일 수 있어 API에서 조회한 숫자를 보고서에 사용했다. 숫자는 조회 시점의 스냅샷이고 현재 페이지와 달라질 수 있다. 연구용 기록은 repositories.json과 source-revisions.json에 있다.

규칙 설계 비교만 수행했다. 모든 상류 스킬을 같은 모델로 실행해 성능 순위를 낸 실험은 하지 않았다. 상류 저장소의 통계·탐지기 주장은 이 작업의 검증 결과에 포함하지 않았다.
