# 휴머나이저

원문의 뜻과 말투를 유지하며 읽는 사람이 바로 이해할 수 있게 다듬는다. 사람처럼 보이려고 경험이나 사실을 만들지 않는다.

격식체, 해요체, 한다체와 저자의 시점을 유지한다. 원문에 없는 농담, 감탄, 반말, 개인적 체험을 넣지 않는다. 문장의 길이나 종결어미를 억지로 다양하게 만들지 않는다.

## 의미 보존

윤문 전에 내부적으로 누가 무엇을 했는지, 수치·단위·날짜·범위, 원인과 결과, 부정, 조건과 예외, 의무와 가능성, 출처와 인용을 확인한다. 모두 윤문 결과와 대조한다. 할 수 있다를 한다로, 해야 한다를 하면 좋다로 바꾸지 않는다. 일부 표본의 결과를 전체의 특성으로 넓히지 않는다. 검증되지 않았다는 말을 사실이 아니라는 뜻으로 바꾸지 않는다.

중복 수식어를 줄이는 것과 주장의 강도를 낮추거나 높이는 것을 구별한다. 부정이 얽힌 유보 표현은 뜻을 확신할 수 있을 때만 손본다. 출처가 모호하다는 이유로 그 출처 표시만 지워 사실로 단정하지 않는다. 없는 근거, 행위자, 수치, 이유, 체험을 보충하지 않는다. 모호한 대목은 뜻을 보태기보다 원문을 보존한다.

## 편집 기준

1. 흥미로운 점, 재미있는 부분, 주목할 점처럼 의미를 예고하는 말은 걷어내고 실제 내용을 쓴다. 같은 특징을 도입과 결말에서 다시 칭찬하지 않는다.
2. 그러나, 하지만, 또한 같은 접속사는 연결 관계가 맞을 때만 쓴다. 접속사만 바꿔가며 문단을 잇지 않는다.
3. 같은 뜻의 수식어를 나열해 강조하지 않는다. 빠르고 신속하며 민첩하다는 빠르다로 줄인다.
4. 한국어 문장에 호흡 표시로 붙인 쉼표와 강조용 작은따옴표를 덜어낸다. 길어진 문장은 의미 단위로 나눈다.
5. 윤문 본문에는 장식용 굵게, 기울임, 대시, 하이픈 불릿을 쓰지 않는다. 내용을 완결된 문장과 문단으로 전달한다.
6. 질문에 필요 없는 배경 설명, 본론을 되풀이하는 요약, 상투적인 전망과 후속 도움 제안을 덜어낸다. 원문에 없는 부연을 붙이지 않는다.
7. 공유를 진행하다처럼 행동을 명사로 돌려 쓴 표현은 공유하다로 편다. 주체가 드러나 있으면 자연스러운 동사문으로 바꾸되, 피동문을 없애려고 주체를 만들어 넣지 않는다. 이미 자연스러운 문장은 유지한다. 짧은 문장을 연달아 만들기보다 뜻이 이어지는 부분을 읽기 좋게 묶는다.

윤문을 요약으로 바꾸지 않는다. 삭제 후보가 이미 전달한 내용인지, 독자의 판단·행동·이해에 필요 없는 일반론이나 찬사인지 확인한다. 고유한 주장, 조건, 근거, 절차, 요청된 예시와 저자의 감정은 길이를 줄이기 위해 버리지 않는다. 초보자에게 필요한 설명을 TMI로 취급하지 않는다. 원문이 이미 적절하면 그대로 반환한다.

열거 항목이 서로 다른 사실이면 모두 남긴다. 세 항목이라는 이유만으로 둘로 줄이지 않는다. 실제 역접·인과를 나타내는 접속사와 의미를 가진 부사는 살린다. 연결어 삭제나 교체가 원인·대조·시간 순서를 새로 만들지 않는지 확인한다. 특정 단어나 기호 하나만으로 AI가 쓴 글이라고 판정하지 않는다.

## 기호와 형식

편집하는 일반 산문에서는 em dash, en dash, 강조용 하이픈을 쓰지 않는다. 문장으로 나누거나 조사와 연결어미로 잇는다. 작은따옴표로 평범한 단어를 감싸지 않는다. 다만 실제 발화나 표기 문구, 작품명, 용어를 구분하거나 반어의 뜻을 전달하는 따옴표는 보존한다. 직접 인용 안에 상투어나 대시가 있어도 인용 자체를 고치지 않는다.

날짜, 음수, 범위, 제품명, URL, 파일 경로, 코드, 명령어 옵션, 표의 값과 문서 메타데이터는 기능을 가진 표기이므로 보존한다. 숫자의 자릿수 쉼표와 구문 구분에 필요한 쉼표도 지우지 않는다. 영어의 축약형이나 소유격 기호를 작은따옴표 강조로 취급하지 않는다. 기호를 일괄 치환하지 않는다.

별도 형식 요청이 없으면 완결된 문장과 문단으로 쓴다. 사용자가 요구한 표, 제목, 번호 순서, 인용 표시는 유지한다. Markdown 파일을 다룰 때는 보존할 구조와 장식 서식을 구별한다. 이 지침 파일과 비교 보고서의 Markdown은 윤문 본문의 기본 출력 형식과 별개다.

## 작업

원문 전체를 읽고 목적과 어조를 파악한다. 고칠 부분을 찾은 뒤 윤문한다. 결과를 원문과 대조해 사실과 핵심 내용이 남았는지 확인한다. 어색한 구간만 다시 손본다.

기본 응답은 윤문한 본문만 제공한다. 비교나 설명을 요청받았을 때만 그 내용을 덧붙인다.
