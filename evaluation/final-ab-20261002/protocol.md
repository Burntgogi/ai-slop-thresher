# v1.2.1 최종 후보의 새 문서 비교

2026-10-02 KST. 가상 문화센터의 대관 절차 변경 공지 한 편으로 v1.2.0과 최종 v1.2.1 후보를 각각 한 번 실행한다. 최종 지침 정리 뒤 새 문맥 작성자에게 원문을 요청했다. 작성자는 후보 지침, 과거 공지·평가·피드백을 읽지 않았다고 보고했다. 시설·정책·전화번호 등은 모두 합성 설정이다. 실제 공공기관 정책을 검증하는 시험이 아니다.

원문·작성 기록·공통 요청·의미 목록과 각 버전 지침은 출력 전에 고정한다. v1.2.0은 Git 태그의 본문, v1.2.1은 현재 후보 정본을 복사한다. 두 새 문맥 편집자는 자신의 스킬·경계 사례와 원문·공통 요청만 읽는다. 이전 출력과 제작자 선호, 의미 체크리스트와 기대 수정문은 전달하지 않는다. 최초 결과는 후편집하지 않는다. 새 문맥은 VM 파일 접근 격리가 아니며 공통 시스템 지침·스킬 목록의 영향은 남는다. 정확한 런타임 모델 ID·temperature·seed는 노출되지 않는다.

제작자는 원문과 출력에서 F01~F19, 제목·격식체·산문과 원문에 없는 사실 추가를 대조하고 근거를 기록한다. 제작자는 버전과 설계 의도를 알고 있어 독립 감수로 표시하지 않는다. 의미 보존과 읽기 선호는 별도 판단이다. 날짜·수치·책임·조건·가능성·약속의 누락이 발견되면 최초 기록을 보존하고 필요한 지침만 조정한다. 확인을 위해 지침을 고칠 경우 보완 실행을 별도 구분하며 최대 한 번으로 한정한다.

새 비교 전문은 X/Y로 무작위 배치해 버전명과 제작자 추천을 숨긴다. 사용자에게 읽기 편함·조건의 명확함·어색한 구간과 선호/동률을 요청한다. 이전 공지에서 받은 B/C 선호는 이번 새 문서의 투표로 쓰지 않는다. 사람 평가는 직접 응답을 받기 전까지 pending으로 둔다.

예전 공지의 원출력·의미 감수·사람 피드백은 회귀 검토 자료로 읽고 원본을 바꾸지 않는다. 새 문서는 최종 지침 설계 때 미노출인 입력이지만 한 편의 합성 사례이므로 전체 성능·통계적 우월성은 판단하지 않는다. 내용 없는 칭찬 제거 등 원문에 나타나지 않은 기능도 이 시험으로 입증하지 않는다.

H: 저장소에서 후보를 준비한다. 동일 원격의 C:/work/human은 v1.1.0 기반의 별도 미커밋 소개 페이지 변경을 보존한다. 설치본은 v1.2.0으로 유지한다. 이번 범위는 최종 지침 정리, 새 문서 비교, 형식·참조·ZIP 검사와 검토 후보 준비다. 커밋·태그·게시·설치는 수행하지 않는다.
