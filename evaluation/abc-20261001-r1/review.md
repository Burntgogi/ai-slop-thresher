# 최초 A/B/C 확인

원문 1편을 각 버전으로 새로 윤문했다. alpha=v1.1.0, beta=v1.2.0, gamma=v1.2.1 첫 가독성 후보다. 각 출력·입력의 해시를 실행 기록과 대조했다. 최초 출력은 후편집하지 않았다.

v1.2.1은 “6건은 조정을 마쳤으며, 나머지 2건은…”의 경계 쉼표와 “결정하실 때에는”을 유지했다. 연락 기한과 완료 보장은 두 문장으로 분리했다. 그러나 원문의 “예약 과정에서 발생할 수 있는 문제”를 “예약 과정의 문제”로 축약했다. 일반적인 문제의 범주로 읽힐 여지도 있으므로 실제 발생을 단정한 문법 오류라고 확정하지 않는다. 원문의 가능성 표시가 덜 분명해져 보수적인 의미 보존 기준에서는 보완 대상으로 판정했다. 이 판단은 제작자의 사후 문장 검토이며 독립 판정이 아니다.

v1.1.0·v1.2.0은 해당 가능성 표시를 유지했다. v1.1.0은 연락 대상을 “아직 처리되지 않은 예약의 이용자”로 구체화했다. 문맥에 맞는 해석이지만 원문은 “남은 이용자”이므로 작성자 확인이 필요한 해석을 모델이 택했다는 차이도 남긴다. v1.2.0은 마지막 표본 설명을 두 문장으로 나누었다.

이번 결과는 스타일 수정과 의미 보존이 함께 확인되어야 한다는 사례다. v1.2.1의 가능성·조건이 명사를 수식할 때도 보존하는 기준을 추가하고, 세 버전을 다시 한 번 같은 조건으로 실행하기로 했다. 후속 실험은 별도 abc-20261001-r2에 기록한다. R1과 R2의 v1.2.1 지침이 다르므로 두 실행을 같은 고정 버전의 반복 성능으로 합산하지 않는다. 후보를 고친 뒤 다시 확인한 과정이며 미노출 자료의 검증으로 주장하지 않는다.
