# v1.1.0 / v1.2.0 / v1.2.1 후보 문서 A/B/C 계획

2026-10-01 KST. 동일한 가상 도서관 공지 한 편, 각 버전 1회, 총 3개 출력을 만든다. 과거 문서 시험의 원문을 재사용하는 가독성 회귀 확인이다. 지침 설계자가 이미 원문과 과거 출력을 읽었으므로 미노출 자료에 대한 일반화 시험은 아니다. 과거 출력은 이번 실행에 섞거나 다시 채점하지 않는다.

스킬 제작 지침의 독립 행동 검증 절차를 적용한다. 의미·조건·책임을 보존하면서 문장 구조를 바꾸는 판단을 실제 출력으로 확인하기 위해 버전별 편집자를 새 문맥으로 분리한다. 편집자는 자신의 고정 지침과 경계 사례, 원문과 공통 요청만 읽는다. 다른 버전과 과거 출력, 사용자 선호 이유, 보존 체크리스트와 목표 수정문은 전달하지 않는다. 새 문맥은 파일 접근을 격리한 VM이 아니며 공통 시스템 지침과 스킬 목록의 영향은 남는다. 런타임 모델 ID·temperature·모델 seed는 노출되지 않는다.

v1.1.0과 v1.2.0 지침은 고정 Git 태그에서 추출하고 v1.2.1은 현재 후보에서 복사한다. 사용자의 설치본은 전환하지 않는다. 각 입력 바이트·보존 목록·요청을 출력 전에 고정한다. 최초 출력은 저장한 뒤 윤문하거나 교체하지 않는다. 출력에 문제가 있어도 최초 결과와 재수정 결과를 구별한다.

Codex는 원문과 최초 출력에서 F01~F15의 의미 보존을 수동 대조하고 근거 구간을 기록한다. 제목·격식체·산문 형식과 원문에 없는 사실 추가도 확인한다. 이 판정은 버전 매핑과 설계 의도를 아는 제작자의 평가이며 독립 심사로 표시하지 않는다. 스타일 해석에서는 쉼표 위치, 조사·연결 표현, 주어·서술어와 명사화, 필요한 부정을 따로 살핀다. 문자 수·쉼표 수는 관측값으로만 기록하고 품질 점수로 쓰지 않는다.

사용자에게는 무작위 순서의 A/B/C 전문과 원문을 제공한다. 버전명과 제작자 추천은 비교문에 넣지 않는다. 전체 읽기 편함, 사실·조건의 명확함, 어색한 구간과 선호/동률을 평가할 수 있게 한다. 이미 과거 출력에 노출된 사용자이므로 완전한 블라인드라고 주장하지 않는다. 아직 받지 않은 사용자 평가는 pending으로 남기며 첨부된 과거 댓글을 이번 표로 옮기지 않는다.

문서 한 편의 각 1회 실행은 반복 생성의 변동이나 전체 버전 우열을 추정하지 못한다. 이 공지에는 내용 없는 흥미·칭찬이 없어 해당 제거 기능은 이 비교로 판정하지 않는다. Dot·Muse 발송, VM 검증, 협업 도구 변경, 설치·커밋·릴리즈 게시를 수행하지 않는다.
