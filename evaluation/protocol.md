# 평가 방법

작성일: 2026년 9월 12일.

이 작업은 현재 작성 에이전트가 수행하는 탐색적 자체 평가다. 별도 모델 API, 외부 탐지기, 독립 평가자 또는 사람 대상 실험을 사용하지 않는다. 미적용 대조군은 이 작업에서 작성한 가상 AI 초안 원문 그대로다. 스킬 적용군은 같은 원문을 해당 버전의 지침에 따라 이 에이전트가 윤문한 결과다. 원문의 사실은 예문을 위한 가상 설정이며 외부 사실 주장으로 사용하지 않는다.

초기본 v0에서 시작해 다섯 번 수정한다. 매 회차마다 기존 결과 또는 구체적인 경계 사례를 검토하고 규칙을 수정한 뒤 새 결과를 기록한다. 의미를 일부러 훼손한 출력을 생성해 성능 향상으로 포장하지 않는다. 출력에서 발견한 문제와 지침에서 발견한 모호함을 구분한다.

기본 비교 사례는 회차에 따라 누적한다. 각 회차 결과와 최종 전체 사례에 대한 검사는 저장된 문자열, 표면 표현, 수치 및 보호 구간을 대상으로 실행한다. 이 검사는 글을 생성하지 않으며 자연스러움이나 전체 의미 보존을 입증하지 못한다. 최종 의미 검토는 명시된 원문 명제와 윤문을 작성 에이전트가 대조한 자체 판단이다.

수정 후 별도의 전이 사례를 새로 작성해 점검한다. 독립적으로 수집한 홀드아웃 코퍼스는 아니며 해당 결과는 일반화 성능으로 해석하지 않는다. 높은 변화율이나 짧은 길이만으로 좋은 윤문으로 평가하지 않는다.

판정은 의미 보존을 먼저 보고, 사용자 지정 표현 감소와 문장 연결, 원래 말투, 요구된 형식을 함께 확인한다. 종합 인간다움 점수나 탐지 회피율은 산출하지 않는다.
