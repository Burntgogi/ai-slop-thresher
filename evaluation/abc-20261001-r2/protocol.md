# 수정 후 A/B/C 확인

2026-10-01 KST. abc-20261001-r1의 원문·요청·의미 목록을 바이트 단위로 유지하고 세 버전의 새 문맥 편집자로 각각 한 번 더 실행한다. R1은 v1.2.1 최초 후보의 가능성 수식어 축약을 발견한 탐색 실행이다. R2의 v1.2.1에는 명사를 꾸미는 가능성·조건도 보존하는 기준을 추가했다. v1.1.0과 v1.2.0의 고정 지침은 R1과 같다.

R1 지침과 R2 지침을 같은 v1.2.1의 두 반복으로 합산하지 않는다. 생성자에게 R1 출력이나 문제·수정 방향을 보여 주지 않는다. 첫 완성본을 저장한 뒤 후편집하지 않는다. 이번 공지문은 지침 설계에 이미 사용한 입력이며 일반화나 버전 전체의 우열을 입증하지 않는다. 런타임 모델 ID·temperature·모델 seed는 노출되지 않는다. 새 문맥은 파일 접근을 격리한 VM이 아니다.

원문 F01~F15, 명사 수식어의 가능성과 절차의 행위자, 제목·격식체·산문 요청, 원문에 없는 사실 추가를 제작자가 대조한다. 의미 보존 판단과 문체 선호를 분리한다. 사용자에게는 무작위 순서의 A/B/C 전문을 제공하고 아직 받지 않은 평가는 pending으로 둔다. 제작자는 버전과 설계 의도를 알고 있어 독립 판정자로 표시하지 않는다.

이 문서에는 정보 없는 흥미·칭찬이 없어 해당 제거 기능은 비교하지 않는다. 같은 문서에 대한 출력 변동을 관찰하되 통계적 동등성이나 우월성을 주장하지 않는다. 독립 편집자 실행 기록은 해시로 대조하고 과거 공개 평가·ZIP·설치본의 보존도 확인한다. Dot·Muse 발송, 협업 도구 변경, 설치·커밋·릴리즈 게시는 수행하지 않는다.
