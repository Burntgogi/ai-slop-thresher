# 1.2.0·1.2.1 실행 회귀 점검과 1.2.2 교정

2026년 10월 7일에 기록했다. 배포된 v1.2.1 지침을 모델로 실행해 비교한 첫 기록이다. 이전의 1.2.1 비교는 중간 후보를 대상으로 했고, 배포본은 제작자가 쓴 예시 9건을 손으로 대조한 것뿐이었다.

## 방법

Codex `gpt-6.1-sol`을 추론 강도 xhigh로 사용했다. `codex exec` 0.160.1을 읽기 전용 샌드박스와 저장하지 않는 세션으로 실행했다. 각 버전의 태그에서 꺼낸 `skills/`만 작업 폴더에 두고, 그 폴더의 SKILL.md만 따르도록 요청했다. 실행 이벤트에서 사용자 설치본 스킬 경로를 읽은 경우는 없었다. 이벤트 로그에는 작업 PC의 경로가 들어 있어 공개하지 않고 작성자 PC에 보관했으며, results.json에는 실행별 판정만 남겼다.

사례는 기존 고정 사례 20개(C01~C12, T01~T08)와 1.2.1의 위험 지점을 겨냥한 탐침 7개다. 탐침은 조건 병합(P01), 배타 조건 만(P02), 개별 적용 단위(P03), 가능성 수식(P04), 지시어와 재배치(P05), 긴 부정 조건문(P06), 이미 자연스러운 글(P07)을 다룬다. 탐침 원문과 추가 판정 기준은 [probes.json](probes.json)에 있다.

v1.2.0과 v1.2.1을 사례마다 2회씩 실행했다(108회). 출력은 `evaluation/check_results.py`의 의미 검사와 탐침별 추가 기준으로 판정한 뒤, 실패하거나 두 버전이 갈린 사례를 모두 직접 읽었다. 전체 출력과 판정은 [results.json](results.json)에 있다. [run.py](run.py)와 [analyze.py](analyze.py)로 다시 실행할 수 있으며 Codex 실행 파일은 `CODEX_BIN`으로 지정한다.

## 결과

| 버전 | 자동 검사 통과 | 원문 대비 평균 길이 |
| --- | ---: | ---: |
| v1.2.0 | 43/54 | 0.89 |
| v1.2.1 | 43/54 | 0.93 |

자동 검사 실패를 직접 읽은 결과 C08을 제외한 실패는 모두 검사기의 문자 일치 한계였다. C04의 입증하는 것은 아니다와 입증하지는 않는다, C12의 번호 뒤 제목 유지, T03과 T07의 어미 변화, T08의 제시되어 있지 않습니다와 제시되지 않았습니다, P03의 두 차례와 2회, P06의 승인하지 않으면 불가와 승인한 경우에만 가능은 뜻이 같다. 두 버전 모두 의미 손실은 없었다.

v1.2.1에서 퇴보한 사례가 하나 있었다. C08에서 실제 표시 문구 '무료'의 곧은 따옴표를 둥근 따옴표로 바꿨다. v1.2.1은 2회 모두 바꿨고 v1.2.0은 2회 모두 유지했다. 뜻은 같지만 기능을 가진 표기를 보존한다는 규칙에 어긋난다. 1회차는 유료 전환 전에를 유료로 전환되기 전에로 바꿔 필수 표현 검사에도 걸렸으나 이쪽은 뜻이 같다.

v1.2.1이 나아진 사례도 있었다. P05에서는 우천 시 조명 제한 문장을 해당 날짜가 정해지면 연락하겠다는 문장 앞으로 옮겨 지시 대상이 분명해졌다. 2회 모두 같은 방향이었고 v1.2.0은 원래 순서를 유지했다. C02에서는 이는 중요한 안내입니다 같은 정보 없는 문장을 더 덜어냈다. P01에서는 두 버전 모두 강조 수식어를 일부 남겨 차이가 없었다.

1.2.1에서 우려했던 조건 병합, 배타 조건 삭제, 가능성 약화, 개별 적용 단위 손실, 자연스러운 글의 과잉 수정은 어느 버전에서도 나타나지 않았다.

## 1.2.2 교정과 재확인

본 스킬에 보존하는 따옴표와 기호는 모양도 바꾸지 않는다는 문장을 추가했다. v1.2.0에서 설명에서 빠졌던 호출 단서 사람 글처럼 다듬기도 되살렸다.

교정한 지침(SKILL.md 0e12a444)으로 C08을 4회 실행했고 4회 모두 곧은 따옴표를 유지했다. C07, T03은 2회, P05와 C01은 1회 실행해 10회 중 8회가 자동 검사를 통과했다. 실패 2회는 모든 버전에서 같은 T03의 문자 일치 한계이며, P05의 재배치는 유지됐다. 다시 실행하려면 `run.py <작업 폴더> v1.2.2`를 쓴다.

## 한계

같은 모델 계열 하나와 사례당 2회 실행이다. 사례는 모두 합성 자료이며 검사기는 문자 수준의 손실만 잡는다. 문체 선호는 판정하지 않았다. 탐침의 추가 기준은 이 점검에 맞춰 작성했으며 사례 통과 수는 다른 평가 기록과 합산하지 않는다.
