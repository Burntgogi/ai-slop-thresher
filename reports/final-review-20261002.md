# AI Slop 탈곡기 v1.2.1 최종 후보 검토

2026-10-02 KST. 사람 피드백을 반영한 지침을 정리하고, 새 합성 공지문으로 v1.2.0과 최종 후보를 한 번씩 비교했다. 이번 문서에서는 후보의 의미 누락을 발견하지 못했다. 새 문서의 사람 선호는 아직 회수하지 않았으므로 체감 개선이나 버전 전체의 우월성을 확정하지 않는다. 설치본은 v1.2.0이다.

기존 A/B/C에서 외부 응답은 B(v1.1.0) 1명·C(v1.2.0) 2명이고, 사용자는 별도로 C를 선호했다. 이 응답은 당시 후보 R2의 결과에 대한 평가다. 최종 후보는 자연스러운 문단의 역할과 정보 순서를 유지하고, 행위·대상이 압축된 명사구는 필요할 때 동사절로 풀도록 했다. 기능 있는 쉼표와 조사도 남긴다. 이번 마무리에서는 작업 설명의 중복을 줄이고, 긴 문장을 의미 경계가 더 분명해질 때만 나눌 수 있도록 문장 분리 기준을 정리했다. 정보 없는 흥미·칭찬 제거, 부정·책임·조건·가능성 보존과 재검증·재빌드 분리도 유지했다.

새 입력은 가상 문화센터의 대관 절차 변경 공지다. 최종 지침 정리 후 지침과 과거 자료를 읽지 않은 새 문맥 작성자에게 요청했다. 원문·공통 요청·의미 목록·버전별 지침을 먼저 고정하고, 두 새 문맥 편집자에게 자신의 입력만 전달했다. 최초 출력은 각각 한 번 저장했고 후편집하지 않았다. 입력과 출력의 해시가 실행 기록과 일치한다. 새 문맥은 파일 접근을 격리한 VM이 아니며 공통 시스템 지침과 스킬 목록의 영향은 남는다. 런타임 모델 ID·temperature·seed는 확인할 수 없다. 주의 항목은 예약 횟수의 단위다. v1.2.0은 ‘신청자 한 명 또는 한 단체’를 ‘개인이나 단체’로 줄였다. 문맥상 각 신청자별 한도로 읽히지만 명시성은 낮아졌다. 확정적인 의미 오류로 단정하지 않는다. 후보는 단위를 명시적으로 유지했고, ‘공개 추첨을 진행합니다’를 ‘공개 추첨합니다’로 다듬었다. 두 결과의 변화 폭은 작다. 원문이 이미 정돈되어 있어 과도한 재구성을 하지 않는지 살피는 사례다. 19개는 한 문서의 점검 항목이며 독립 시험 19건이 아니다. 제작자는 버전과 설계 의도를 알고 있으므로 독립 감수로 표시하지 않는다. [원문과 문장별 근거](../evaluation/final-ab-20261002/meaning-review.json)

이전 공지의 원출력·의미 감수·사람 응답을 다시 읽어 문단 흐름, 동사절 병렬, 취소의 두 조건과 가능성 보존 기준을 확인했다. 기존 출력을 재작성하거나 과거 투표를 새 후보의 점수로 합산하지 않았다. 이번 새 공지에는 빈 칭찬과 불필요한 재정의가 없어 해당 기능의 행동 개선을 입증하지 않는다. 한 편·버전당 한 번의 결과로 전체 성능이나 통계적 우월성을 판단할 수 없다.

두 스킬의 형식, 정본과 플러그인 생성물 10개 파일의 일치, 상대 참조와 Git 공백 검사를 통과했다. 기존 평가·ZIP·C: 체크아웃·설치본의 보호 대상 269개 파일은 해시가 같았다. 이전 배포물과 후보 폴더도 기록된 체크섬과 CRC를 확인했다. C:의 v1.1.0은 기존 ZIP 2종 목록을 별도로 검사했다. 검사 코드 변경은 없어 전체 테스트를 반복하지 않았으며, 41개 중 38개 통과·3개 건너뜀은 이전 코드 검사의 결과다. [이번 확인 기록](../evaluation/final-ab-20261002/technical-checks.json)

검토 후보의 출력 위치는 소스 밖의 새 폴더 `../../release-candidates/ai-slop-thresher-v1.2.1-final-20261002`다. ZIP 4종, 체크섬, 포함 목록과 빌드 후 소스 보존·ZIP 대조 결과는 그 폴더의 `build-report.json`과 `readiness-check.json`에 기록한다. 이 문서는 사람 평가 전 시점의 기록이다. 비교문 X/Y의 선호 또는 동률과 이유는 [새 비교문](../evaluation/final-ab-20261002/comparison-blind.md)에 대해 별도로 회수하며, 상태는 로컬 `human-review.json`에서 관리한다. 미응답을 승인으로 취급하지 않는다. 커밋·푸시·태그·릴리즈 게시·설치는 수행하지 않았다. 협업 도구와 VM 작업은 이번 범위에 포함하지 않는다.
