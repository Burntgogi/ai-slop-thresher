# AI Slop 탈곡기 v1.2.1 확정 검토

2026-10-02 KST. v1.1.0의 기본 윤문과 별칭, v1.2.0의 의미 보존·하네스별 배포 구조, v1.2.1 후보의 가독성 개선을 정본에 통합했다. 추가 A/B와 사람 투표는 종료하고 기존 사례의 회귀 확인과 배포 검증으로 마무리한다. [릴리즈 노트](../docs/releases/v1.2.1.md)

마지막 변경은 조건·범위·개별 적용 단위를 유지한 표현 압축과 제한적인 정보 재배열이다. 독자의 판단·행동에 필요한 전제가 늦게 나오거나 같은 역할의 정보가 흩어져 읽기 어려울 때만 묶음과 위치를 조정한다. 조건·예외의 적용 대상과 지시어의 선행 대상을 확인하고, 원문에 없는 인과·대조·우선순위를 만들지 않는다. 장르에 맞는 자연스러운 전개를 유지하며 문단 틀을 강제하지 않는다. 조사·접속 표현은 덜어낸 뒤에도 관계가 명확할 때만 줄인다. 빈 칭찬 제거와 감상·인용·책임·가능성 보존 기준은 유지했다.

이전 공지의 사람 응답은 외부 B(v1.1.0) 1명·C(v1.2.0) 2명과 사용자의 별도 C 선호였다. 후속 공지에서는 사용자가 X(v1.2.1 후보)를 대체로 선호하면서 둘째 문단의 길이와 논리적 정보 배열을 보완하도록 의견을 줬다. 이들은 서로 다른 문서·후보에 대한 평가이므로 합산하지 않는다. 최신 X/Y의 최초 출력과 과거 평가·패키지는 보존했으며, 마지막 지침 변경을 그 출력의 생성 조건에 소급해 적용하지 않았다.

| 최종 확인 | 결과와 범위 |
| --- | --- |
| 기존 코드 테스트 | 41개 중 38개 통과·3개 건너뜀. Windows 심볼릭 링크 권한이 필요한 항목을 구분했다. |
| 스킬 형식·생성물·참조 | 두 스킬의 형식, 플러그인 10개 파일의 정본 일치, 상대 참조·카탈로그 경로와 Git 공백 검사 통과. |
| 저장 사례 검사 | 이전 5회 개선과 전이 사례의 저장된 출력 검사·의도적 손상 확인 통과. 새 모델 실행이 아니다. |
| 의미 회귀 확인 | 기존 입력을 사용한 수동 예시 9건에서 빈 칭찬·책임·취소의 두 조건·유보·감상·인용·월별 개별 한도·역접·지시어 연결을 대조했다. 의미 손실을 발견하지 못했다. |
| 기존 파일 보존 | 이전 평가·ZIP·C: 체크아웃 등 보호 대상 211개 파일의 내용 해시가 같았다. |

[기술 검사 기록](../evaluation/release-1.2.1/technical-checks.json)과 [수동 의미 대조](../evaluation/release-1.2.1/regression-review.json)에 실제 범위와 한계를 기록했다. 마지막 지침 변경 후 새 맹검 생성 시험이나 삼자 감수는 하지 않았다. 수동 회귀 예시는 독립 실행 결과나 새 성능 점수가 아니다. 모든 글에서의 품질 우월성을 주장하지 않는다.

확정 배포물의 ZIP 4종·SHA256SUMS·포함 목록은 소스 밖의 새 릴리즈 폴더에 생성한다. 빌드 전후 소스 보존, ZIP 체크섬·CRC, portable/Codex 원본 일치와 workbench 포함 자료는 그 폴더의 `build-report.json`과 `readiness-check.json`에서 확인한다. 같은 확정 소스를 커밋·태그·공개 릴리즈에 사용하고 게시된 ZIP의 해시를 확인한 후 현재 사용자 스킬 경로를 갱신한다. 설치 전 두 스킬은 스킬 검색 경로 밖에 보관한다. 게시·설치의 실제 완료 여부와 복구 위치는 별도 로컬 실행 기록에 남긴다. 이 문서는 게시·설치 전 검토 시점에 작성했다.

협업 도구·VM 배치와 C: 체크아웃의 별도 소개 페이지 수정은 이번 릴리즈 범위에서 제외했다. 현재 공개 안내의 버전만 갱신하고 과거 보고서의 후보·평가 대기 표시는 당시 기록으로 유지한다.
