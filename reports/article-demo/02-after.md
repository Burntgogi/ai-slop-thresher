# AI 문장 다듬는 'AI Slop 탈곡기' 공개…원문 뜻 살리는 한국어 윤문 도구

AI가 쓴 글에서 반복되는 칭찬이나 길어진 설명을 정리하기 위한 도구가 공개됐다. GitHub 사용자 Burntgogi가 2026년 9월 12일 선보인 'AI Slop 탈곡기: 이 글은 흥미롭지 않습니다.'는 Codex에서 사용하는 한국어 윤문 스킬이다.

스킬 지침은 글을 단순히 줄이기보다 원문의 사실과 조건, 수치, 인용, 저자의 말투를 보존하며 표현을 다듬도록 한다. '흥미로운 점은' 같은 도입이나 같은 뜻의 수식어 나열이 주요 검토 대상이다.

문맥에 맞지 않는 접속사와 불필요한 쉼표, 강조용 작은따옴표도 검토한다. 마크다운의 장식용 굵은 글씨나 대시 역시 정리 대상이다. 다만 코드, URL, 날짜와 숫자처럼 기능을 가진 표기는 일괄적으로 지우지 않도록 했다.

배포 ZIP의 ai-slop-thresher와 thresh 폴더를 같은 스킬 디렉터리에 넣은 뒤 Codex에 다듬을 글과 함께 $thresh 또는 $ai-slop-thresher를 입력하면 된다. 스킬 전용 API 키나 Python 설치는 필요하지 않다. Codex가 지침을 읽고 문장을 편집한다.

기본 응답에는 다듬은 본문만 담긴다. 요청에 따라 원문과 수정문을 함께 보여주거나 어색한 구간만 진단할 수도 있다. README 같은 Markdown 파일에서는 제목과 표, 링크, 명령어 등 문서 구조를 유지하도록 요청할 수 있다.

프로젝트에는 스킬 외에도 적용 전후 예문과 제작 보고서가 포함됐다. 제작 과정에서는 초기 지침 이후 5회 개선을 거쳤으며, 기본 예문 12개와 추가 예문 8개의 결과를 기록했다. 참고한 휴머나이저 저장소 7개와 화면·문서 구성에 참고한 저장소 2개의 정보도 함께 정리돼 있다.

다만 예문과 윤문은 같은 에이전트가 작성한 가상 자료다. 저장된 결과의 문자 검사와 자체 의미 검토는 수행됐지만, 독립 평가나 AI 탐지기 통과율을 측정한 결과는 아니다. 따라서 실제 문서를 다듬을 때는 수치와 조건, 직접 인용이 원문과 같은지 다시 확인할 필요가 있다.

현재 공개된 버전은 v1.1.0이며 라이선스는 Apache-2.0이다. 저장소에는 한국어와 영어 README가 마련돼 있다. 영어 README는 한국어 윤문 스킬을 영어로 안내하는 문서이며, 영어 윤문 성능을 별도로 검증했다는 뜻은 아니다. 배포 파일에는 LICENSE와 NOTICE, ATTRIBUTIONS.md가 포함돼 있어 이용 조건과 참고 자료를 확인할 수 있다.

사용자는 공개된 예문으로 수정 방향을 확인한 뒤 자신의 글에 적용할 수 있다.
